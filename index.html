Control de Vencimientos

Registrá, buscá y controlá tus productos fácilmente

📷 Registrar producto

Escaneá el código con la cámara o escribilo manualmente. Si el artículo ya existe, se completarán sus datos.

🧾 Datos del producto y vencimiento

🔎 Buscar artículo

Buscá por código de barras, nombre, marca o categoría. Podés usar un lector que escriba el código y presione Enter.

📚 Catálogo de artículos

Los artículos se incorporan al catálogo al guardar su primer vencimiento. El mismo código puede tener varios vencimientos o lotes.

📋 Historial de retiros

Registro de productos retirados del control activo.

💾 Respaldo de datos

Los datos de esta versión se guardan en el navegador de este dispositivo. Exportá una copia regularmente para no perderlos si cambiás de teléfono o navegador.

Importar reemplazará los datos guardados en esta versión. Exportá primero una copia si querés conservarlos.

ℹ️ Acerca de esta versión

Versión personal independiente. No requiere acceso a la cuenta anterior. No sincroniza automáticamente con la base de datos anterior ni con otros dispositivos.
